# Coastal Explorer photography

Drop production photos here, named exactly as below. The page picks them up automatically;
until a file exists its chapter falls back to the placeholder block, so a missing photo
never breaks the page.

| file | where it appears |
|---|---|
| `hero.jpg` | full-bleed behind the title at the top of the page |
| `tossa-from-above.jpg` | chapter 2 — the Mirador |
| `giverola-from-above.jpg` | chapter 4 — Giverola clifftop |
| `rosamar.jpg` | chapter 5 — Rosamar |
| `sant-elm.jpg` | chapter 8 — Ermita de Sant Elm |

Landscape, 2000px wide or more, straight off the camera. They are resized and compressed
at build time, so do not shrink them first.

Everything here must be owned by Tossa Cycling or explicitly licensed for commercial use,
per `docs/ARCHITECTURE.md`. Where people are recognisable, keep a record that they agreed
to their image being used in marketing — the `credit` and `consent` fields on each chapter's
`image` in the route config are where that is recorded.
