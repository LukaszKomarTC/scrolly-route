# Tossa Highlights route assets

This directory is reserved for the **approved public Tossa Cycling master route** and production-cleared assets for the first reference implementation.

Expected route file:

`public/routes/tossa-highlights/tossa-highlights.gpx`

Do not add a fabricated or approximate route simply to make the prototype look complete. The cinematic prototype becomes route-accurate only when the verified master GPX is present.

Production imagery added here must be owned by Tossa Cycling or explicitly licensed for commercial website use.
